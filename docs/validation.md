## 0.1.3 本地更新

新增双参数记忆、会话删除与批量清除，以及项目思考强度设置。
本地已构建并替换 App；源码、客户端与 macOS 安装包同步至 GitHub，桌面交互由用户手测。

手测时建议覆盖：

- 支持服务端续接的接口上，`default_memory=True, memory=0` 连续问答。
- 不同会话名称的记忆隔离，以及同名会话恢复。
- 显式历史窗口与服务端续接分别开关，接口不支持时的错误提示。
- `clear_memory()` 后名称为 None，下一次提问使用新名称。
- 按项目、跨项目批量清除，项目配置和用量仍可查看。
- 保存项目思考强度，确认下一次请求使用新档位。
